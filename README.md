# 🧠 About the Project

**CampusIQ — APEX Career Intelligence Platform** is an AI-powered campus intelligence ecosystem designed to connect students, faculty members, placement officers, and institutional leadership through a unified digital platform.

The platform focuses on improving student career readiness by bringing essential academic, professional development, and placement-related activities into one integrated environment.

Instead of managing campus career activities through disconnected systems, CampusIQ aims to provide a centralized experience for:

- 🎓 Student Career Development
- 🧠 AI-Powered Career Intelligence
- 📊 Skill Assessment & Gap Analysis
- 📄 Resume Management
- 💼 Job Opportunities
- 🎯 Placement Preparation
- 👨‍🏫 Faculty Coordination
- 🏢 Recruitment Management
- 📢 Campus Announcements
- 📈 Institutional Insights

The core objective is to make career preparation more structured, measurable, accessible, and effective.

---

CampusIQ is designed as more than a conventional college management portal.

Its primary focus is connecting student career development with institutional placement activities.

The platform brings different campus stakeholders into one digital ecosystem.

# 🎯 Project Vision

The vision behind CampusIQ is simple:

> **What if every student could understand their career readiness, identify skill gaps, and prepare for placements through one intelligent campus platform?**

Traditional campus activities often involve multiple disconnected processes. CampusIQ explores a unified approach:

```text
Student Information
        +
Skill Assessment
        +
Career Preparation
        +
Placement Opportunities
        +
Faculty Coordination
        +
Recruitment Management
        ↓
Unified Campus Intelligence
```

The goal is to create a connected campus environment where students can improve their professional readiness and institutions can coordinate placement activities more effectively.

# ⚙️ Local Development

### 1. Clone the Repository

```bash
git clone https://github.com/Krish06-0/CampusIQ.git
```

### 2. Move Into the Project

```bash
cd CampusIQ
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local development URL provided by Vite in your browser.

# 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
